أدخل بريدك الإلكتروني لإرسال رمز التحقق.

سيصلك رمز التحقق على بريدك الإلكتروني.

خطوة 2: تأكيد التسجيل

أدخل رمز التحقق الذي وصل إلى بريدك الإلكتروني.

أدخل الرمز لإكمال التسجيل.

ملاحظات مهمة

  • رمز التحقق صالح لمدة 5 دقائق.
  • تأكد من صحة البريد الإلكتروني قبل الإرسال.
  • إذا لم يصلك الرمز، تحقق من صندوق الرسائل غير المرغوب فيها.

القواعد الأساسية في الرياضيات

قوانين الجبر

  • توزيع: a(b + c) = ab + ac
  • عوامل مشتركة: ab + ac = a(b + c)
  • المربعات: (a ± b)2 = a2 ± 2ab + b2
  • فرق المربعين: a2 - b2 = (a - b)(a + b)

قوانين الأسس والجذور

  • am · an = am+n
  • am / an = am-n
  • (am)n = amn
  • √(ab) = √a · √b

قوانين المثلثات

  • مجموع زوايا المثلث = 180°
  • قانون الجيب: a / sin A = b / sin B = c / sin C
  • قانون جيب التمام: c2 = a2 + b2 - 2ab cos C
  • فيثاغورس: a2 + b2 = c2

الاحتمالات والإحصاء

  • P(A) = عدد النواتج الملائمة / عدد النواتج الكلية
  • المتوسط الحسابي = مجموع القيم / عددها
  • الانحراف المعياري = √(∑(x - μ)2 / n)
  • التباديل: P(n, r) = n! / (n - r)!

حساب المتتابعة الحسابية

المعادلة: an = a1 + (n-1)d

أدخل قيم المتتابعة.

مكتبة المعادلات

الهندسة

  • مساحة الدائرة = πr2
  • محيط الدائرة = 2πr
  • مساحة المثلث = (القاعدة × الارتفاع) / 2
  • حجم الكرة = 4/3 πr3

التفاضل

  • d/dx (xn) = n xn-1
  • d/dx (sin x) = cos x
  • d/dx (cos x) = -sin x
  • d/dx (ex) = ex

التكامل

  • ∫ xn dx = xn+1 / (n + 1)
  • ∫ sin x dx = -cos x + C
  • ∫ cos x dx = sin x + C
  • ∫ ex dx = ex + C

المتتاليات والمتسلسلات

  • مجموع المتتابعة الحسابية = n/2 (2a1 + (n-1)d)
  • مجموع المتتابعة الهندسية = a1 (1 - rn) / (1 - r)
  • مجموع المتسلسلة اللانهائية = a1 / (1 - r) |r| < 1
